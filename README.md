# Project: Node Coin Flip Game

### Goal: Create a simple web application that uses the fs and http modules. Use http to create the server and fs to read your html file. Include vanilla ES6 js in a script tag at the bottom of your html file. Create a coin flip guessing game!

### Features:
- This is a simple coin flip game where the user can write their guess (heads or tails) and check if they've won.
- This game uses a text input, a button with a click event that runs the code, and the server side javascript returns results of the game.
